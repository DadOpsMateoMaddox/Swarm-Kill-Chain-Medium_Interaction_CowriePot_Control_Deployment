P0-RCA-02 — INVALID [shell] processes CONFIGURATION
===================================================
Cowrie 2.5.0 treats [shell] processes as a JSON FILE PATH, not a count.

    /opt/cowrie/src/cowrie/shell/server.py

PRE-REPAIR: processes = 5   ->   open("5")   ->   FileNotFoundError

Only NoOptionError is caught. FileNotFoundError propagates out of
initFileSystem -> request_exec -> SSH_MSG_CHANNEL_FAILURE.

Critically: initFileSystem runs on the FIRST shell/exec request, not at
startup. Cowrie booted clean, listened, and authenticated normally; it
only failed at the moment an attacker tried to act.

REMEDIATION: processes = /opt/cowrie/share/cowrie/cmdoutput.json
(absolute, to remove relative-path ambiguity; CWD is /opt/cowrie)
